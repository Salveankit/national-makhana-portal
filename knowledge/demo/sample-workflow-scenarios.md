# Sample Workflow Scenarios

This file contains seeded demonstration knowledge for the chatbot to explain likely portal behavior when live production data or policy detail is not yet connected.

Illustrative beneficiary scenarios:

- A farmer submits an application and receives a status of Submitted.
- A state officer reviews the application and may raise a clarification if documents or cost details need improvement.
- After clarification, the officer may assign a field inspection.
- An inspector completes a geo-tagged field verification and records remarks.
- The state officer may recommend the case to the National Makhana Board.
- The Board may approve, return, or reject the case based on review.

Illustrative planning and monitoring scenarios:

- A state officer submits an Annual Action Plan for a financial year.
- NMB reviews the plan and can approve or return it with remarks.
- Budget allocation and utilization records can be monitored through dashboard summaries.
- Notification and integration event logs can be reviewed for operational transparency.

Illustrative support positioning:

- Demo answers should help users understand what the portal is capable of.
- Demo answers should not claim that a live provider or a live government system has already completed an action unless the portal record explicitly shows it.
