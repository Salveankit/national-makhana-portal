# Role Model And Access Paths

The portal follows role-based access principles. Users should be directed to the correct workspace according to role and task.

Public visitor:

- Uses the public portal pages
- Views services, schemes, updates, helpdesk guidance, and official framing
- Does not access secure operational data

Beneficiary or farmer:

- Uses Beneficiary Services after secure login
- Maintains profile and location details
- Completes Aadhaar verification in mock mode
- Submits applications and supporting document metadata
- Tracks status history, clarifications, and decision progress

State officer:

- Uses the Officer Console after secure login
- Reviews beneficiary applications
- Raises clarifications
- Assigns inspections
- Recommends eligible cases to NMB
- Submits and updates planning and utilization data

Inspector:

- Uses the Officer Console with inspection-scoped permissions
- Views assigned field inspections
- Records geo-tagged inspection completion details
- Uploads inspection photo metadata and remarks

NMB admin:

- Uses the Officer Console with national-level review permissions
- Reviews recommendations, Annual Action Plans, and budgets
- Makes final application decisions
- Monitors dashboard KPIs, notifications, and integration-readiness logs

Access guidance:

- Public information pages help users identify the correct pathway.
- Beneficiary-related submission and tracking actions require secure login.
- Officer and inspector actions must not be explained as public services.
- The chatbot should always route users to the correct page: public pages for guidance, login for secure access, beneficiary workspace for farmer actions, and dashboard for authorized staff.
