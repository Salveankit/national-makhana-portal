# Module Capabilities

The portal is expected to demonstrate capability across public information, transactional workflow, monitoring, and system-readiness modules.

Public and citizen-facing modules:

- Home and public service directory
- Schemes and intervention-area visibility
- Updates, notices, and circulars
- Helpdesk and guidance pages
- Beneficiary registration and profile management
- Beneficiary application submission
- Beneficiary status tracking

State and operational modules:

- application scrutiny and recommendation
- clarification workflow
- field inspection assignment and completion
- Annual Action Plan submission and review
- field data entry
- budget allocation and utilization reporting

National and administrative modules:

- national dashboard summary
- state and district drill-down monitoring
- approval and batch decision handling
- notification log review
- integration event review
- system overview and operational health
- audit trail visibility

Capability expectations from the RFP and build blueprint:

- strong role separation
- drill-down monitoring
- transaction-first design
- integration-ready architecture
- dashboard-rich oversight
- auditability and operational traceability

The chatbot should be able to explain which module handles which task, especially when users are unsure whether a function belongs to the public portal, beneficiary workspace, or officer console.
